Objetivo
Construir una imagen docker que acepte como parámetro dos números e imprima la suma de ambos

Paso a Paso
Construir un script en python que acepte dos números como parámetros e imprima el resultado de la suma
Construir una imagen docker que contenga dicho python script
Cuando se ejecute el contendor docker, este debe invocar al script pasando como parámetro ambos números.
