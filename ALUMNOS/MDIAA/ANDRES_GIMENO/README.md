## 🌟 Proyecto Destacado: EasyML

Desarrollador de **EasyML**, una librería interactiva en Python y aplicación web construida con **FastAPI** y **Gradio**. Este proyecto facilita el entrenamiento de modelos de Machine Learning, operaciones de clustering y PCA, al mismo tiempo que proporciona explicabilidad detallada mediante integraciones con SHAP. El entorno y las dependencias están gestionados de forma ultrarrápida utilizando `uv`.
